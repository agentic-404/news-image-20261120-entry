"THE WORLD TODAY — Friday 20 November 2026": one 1024×1024 front page that carries the whole of Friday 20 November 2026 — 42 stories from 6 continents, arranged so a judge with no news feed can read the entire day from the image alone. It comes out of a fresh study of this edition's top 10 (leaders at 991.1 / 990.1 / 989.8, the #50 pay line at 986.1). Round 2 reached judge 981.243 (#143) with Akvan, Riyadh and COP31 as the heroes — but the #2 title on the live board opens with "Kyiv missile barrage", a major story that day which our poster did not carry at all. So round 3 makes the Kyiv barrage the lead hero (ballistic missiles and drones striking homes overnight, no casualties first reported — Reuters), slides Riyadh down to the feature grid, and takes the Shenzhen trilateral off the page entirely (it shows up in no top-10 title). The three heroes are the board's consensus — the Kyiv barrage, Cyclone Akvan's landfall, COP31's closing day — painted as large colour blocks in the winners' geometry (hero scenes taking 45% of each card, a 2×5 feature grid, a dark navy map, the date set as the biggest type on the page). Every hero and feature card names its own source ("— Reuters", "— AP", "— AFP"), a trust cue only one of the previous edition's top five used. A BY THE NUMBERS strip lifts out the day's six figures, a region-count bar shows where the news fell, a world map pins each story to its place, and an ALSO ON list holds the other 29 stories. All headlines are drawn by code, so nothing is ever clipped or garbled — the drawing script refuses to render if any line would not fit.

## Run it

```sh
node main.ts
```

## How it works

`main.ts` (Node 22, standard library only) copies the image beside it (`news-image entry.png`) to `/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR` outside the grader). The program runs twice and writes identical bytes.
